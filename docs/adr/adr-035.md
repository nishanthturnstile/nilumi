# ADR-035 — Web Push and delivery-stage evidence

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P5. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the web push and delivery-stage evidence choice within that experience.

## Decision

Use per-device VAPID Web Push. Household previews show text by default/configurably; private reminders and briefs use generic previews. Always create Inbox regardless of push. Measure dispatch, service acceptance, service-worker receipt and user acknowledgement separately.

## Consequences and validation scope

Installed iPhone permission and real-device tests are required. Revoke 404/410 subscriptions, retry eligible failures and show overdue/failure state. Notification deep links restore the authorized Home activity; acceptance is not guaranteed alarm-grade presentation.
