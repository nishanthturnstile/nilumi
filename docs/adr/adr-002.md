# ADR-002 — TypeScript end-to-end (pnpm monorepo, shared Zod contracts)

> **Status:** Accepted
> **Baseline:** Revision 2, reviewed 6 Oct 2026; individual decision date not recorded
> **Origin:** Extracted from Architecture §21; existing ID and accepted meaning retained
> **Legacy references:** Original ADR only

## Context

A single part-time developer needs shared runtime contracts across client, API, domain logic and jobs.

The topology review favors one app/API deployable and an always-on TypeScript worker. This supports keeping one language; it does not establish a new language benchmark.

## Decision

TypeScript covers the Next.js app, Hono API, shared contracts, domain logic, worker and tests.

## Alternatives

Python FastAPI + TS PWA; NestJS.

## Consequences

one language and type-safe client/server; Python can be added later only as an isolated sidecar if a future local-ML/Vault need justifies it.

The documented runtime and dependency versions remain in Tech Stack and are pinned when the project starts.
