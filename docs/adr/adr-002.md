# ADR-002 — TypeScript application and isolated Python voice service

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P0–P1. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the typescript application and isolated python voice service choice within that experience.

## Decision

Use TypeScript for Next.js/React, Hono application APIs, deterministic domain execution, workers and shared Zod contracts. Use an isolated Python Pipecat service for media, STT/TTS framing, endpointing and interruption. Exchange versioned JSON contracts over authenticated service connections; publish JSON Schema and Python validation equivalents from the contract definitions. Python cannot import Zod or own a parallel household database/executor.

## Consequences and validation scope

Use this existing pnpm workspace and extend packages/ui in place. Planned apps/web, apps/worker and services/voice do not exist yet. Contract compatibility, schema validation and version-skew tests gate deployment; Python pins its own dependencies and supported formatting/lint tools.
