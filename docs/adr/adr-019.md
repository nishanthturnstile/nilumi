# ADR-019 — Grounded text, presentation and speech

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P4–P6. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the grounded text, presentation and speech choice within that experience.

## Decision

Use deterministic templates for single-fact answers. Optional synthesis is sentence-gated against member-visible evidence before text display or speech. Presentations cite the same sources and revisions. Missing evidence produces explicit abstention, not inferred household facts.

## Consequences and validation scope

The renderer and TTS do not invent success messages. Newly generated explanations/drafts remain activity content until an explicit authorized domain write. Forgotten or unshared sources invalidate answer/presentation/audio references.
