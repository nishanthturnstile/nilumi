# ADR-007 — Visibility enforced by Postgres row-level security

> **Status:** Accepted
> **Baseline:** Revision 2, reviewed 6 Oct 2026; individual decision date not recorded
> **Origin:** Extracted from Architecture §21; existing ID and accepted meaning retained
> **Legacy references:** Original ADR only

## Context

A spouse must not see another adult's private content or infer that it exists, including through derived views.

The review identifies leaks through history, private entities and shared projections, beyond filtering memory rows. These paths require member-scoped access and privacy evaluation.

## Decision

RLS is the privacy boundary for household, shared and private data.

## Alternatives

app-layer filtering only.

## Consequences

defense-in-depth against leaks between spouses; every request sets its context in a transaction; admin views are designed around RLS.

Pooled-context isolation and the 100% privacy gate remain mandatory; [ADR-031](adr-031.md) records the product defaults.
