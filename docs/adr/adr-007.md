# ADR-007 — RLS privacy and household isolation

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P1–P8. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the rls privacy and household isolation choice within that experience.

## Decision

Enforce household, owner and sharing visibility with PostgreSQL row-level security plus backend authorization. Bind household/member context from the authenticated session in each transaction. Every household-owned row, join and ledger includes household_id; composite foreign keys and triggers prevent cross-household references. Admin does not bypass private visibility.

## Consequences and validation scope

Privacy tests include second-household fixtures, pooled-connection context, existence leaks, speech, generated layouts, Recent, history and offline projections. A visibility-filtered UI alone is insufficient. Zero leaks is a release gate.
