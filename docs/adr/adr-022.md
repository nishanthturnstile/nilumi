# ADR-022 — Gateway model routing and restricted-pilot controls

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P1. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the gateway model routing and restricted-pilot controls choice within that experience.

## Decision

Route LLM and embeddings through Vercel AI Gateway using purchased credits and managed credentials, behind one AI SDK role registry/wrapper. No BYOK or direct-provider bypass. On every request enforce disallowPromptTraining:true, only:[openai] for the currently verified roles, supported store:false, catalog freshness/eligibility checks and routing/cost receipts. Fallbacks remain disabled in the restricted pilot. STT/TTS are direct approved speech connections.

Unknown provider, BYOK, stale/ineligible model, missing receipt or unknown cost halts the role. HTTP402 quota_for_entity_exceeded, credit exhaustion and no_providers_available are terminal with no retry/challenger fallback. CI guards model construction so all calls use policy and hard reservation controls. If embeddings have no eligible route, use FTS/trigram retrieval.

## Consequences and validation scope

Consolidates ADR-038 and applicable ADR-046/052. Four historical negative-policy probes returned HTTP500 and remain failed. The founding pilot accepts documented forwarding/retention and compensating local guards for this exception; use beyond the restricted founding-household pilot requires explicit negative rejection and ZDR proof under ADR-017. S3 correctness acceptance and S-VGW quota/control acceptance do not prove new production integration.
