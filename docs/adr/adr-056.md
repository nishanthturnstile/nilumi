# ADR-056 — Pastel foundation for stable Home

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** selected for prototype; P0/P2. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the pastel foundation for stable home choice within that experience.

## Decision

Retain existing OKLCH stylesheet, Nunito/Noto Sans Tamil, contrast rules, Phosphor icons and customized shadcn Base UI/maia foundation. Use a stable Home shell with contextual activity accents, white cards, navy ink and coral voice controls. Existing room-token names remain unchanged compatibility identifiers, not five navigation tabs.

## Consequences and validation scope

Theme/text scale 100–200% initialize before paint; portals inherit tokens; type scaling does not inflate spacing. Accessible composer, speech indicators, Recent and renderer transitions replace tab-wayfinding guidance. Static specimens and prior design reviews are reference evidence, not current Home specification or installed-phone proof.
