# ADR-027 — Foreground speech controls and output defaults

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P0/P2. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the foreground speech controls and output defaults choice within that experience.

## Decision

Voice input defaults to short spoken responses plus visible text/presentation. Typed input defaults to quiet visible output. Auto/always/off output preference, per-response Replay, Mute and Stop remain available in Home. A tap opens the foreground session; End conversation releases media.

## Consequences and validation scope

Mute controls output only; stop cancels current playback; interruption starts a new turn. Playback failure leaves the visible result and explicit replay gesture. Backgrounding and reconnection cannot replay old speech or duplicate actions.
