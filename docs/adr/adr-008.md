# ADR-008 — Streaming conversational speech with auditable text

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** selected for prototype; P0. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the streaming conversational speech with auditable text choice within that experience.

## Decision

Select cascaded streaming STT → authoritative turn service → validated response → streaming TTS for the prototype. Pipecat manages media and interruption; Sarvam supplies speech. Preserve recognized final spans for deterministic validation and evidence. Partial recognition is provisional and cannot execute writes.

## Consequences and validation scope

REST clip measurements remain historical evidence, not the new interaction specification. Direct end-to-end speech-to-speech is not selected because actions and answers require auditable authoritative text. New processor, transport and full-turn phone validation are pending.
