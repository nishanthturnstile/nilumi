# ADR-001 — Channel-agnostic brain; Next.js PWA first; Home Assistant later

> **Status:** Accepted
> **Baseline:** Revision 2, reviewed 6 Oct 2026; individual decision date not recorded
> **Origin:** Extracted from Architecture §21; existing ID and accepted meaning retained
> **Legacy references:** Original ADR only

## Context

Both adults need a phone identity and visible capture/correction flow before adding a shared room device.

A phone UI supports transcript cards, memory browsing and explicit ownership. The iPhone capability review identifies platform limits that any web framework must prove in S1.

## Decision

the PWA and `/v1` API are the first channel, with Home Assistant later as an adapter to the same turn contract.

## Alternatives

Home Assistant-centric local setup; Telegram/WhatsApp bot; native apps.

## Consequences

identity is solved per phone, the trust UX (cards, undo, memory browser) stays first-class, and HA arrives without core rewrites.

S1 must prove phone usability; H2 remains later, after the H1 Vault.
