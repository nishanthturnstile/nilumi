# ADR-057 — Home canvas and persistent activities

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** selected for prototype; P0/P2. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the home canvas and persistent activities choice within that experience.

## Decision

Home combines brief, conversation controls and one focused activity. A topic change saves prior state and focuses a new activity; Recent restores authorized current activity independently of conversation expiry or app reopening. Activities own identity, member, domain references and revision; presentations are validated derived layouts bound to activity/data revisions.

## Consequences and validation scope

Voice/text/touch share active context. Layout changes preserve domain IDs and checked state and do not automatically create facts/tasks. Archive hides activity; delete removes owned draft/layout; source forget/visibility changes scrub references. Preserve focus during interaction, reject stale generation/audio and restore safe fallbacks. Household records and member-owned activities are separate authorities.
