# ADR-049 — PWA channel; no WhatsApp integration

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P5/Deferred. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the pwa channel; no whatsapp integration choice within that experience.

## Decision

Use PWA voice/text/touch and Web Push. Do not implement a WhatsApp channel. Additional messaging adapters remain deferred and require current eligibility review; pasted/forwarded text is untrusted input through Home.

## Consequences and validation scope

Historical channel-term findings remain dated research and are not universal current legal advice. No unofficial WhatsApp adapter, native share extension contingency or alternate channel build is required.
