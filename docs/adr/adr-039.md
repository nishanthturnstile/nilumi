# ADR-039 — S1 outcome: PWA kept on both phones; Capacitor fallback not triggered

> **Status:** Accepted
> **Baseline:** October 2026
> **Origin:** S1 spike result on the two household phones (iPhone/iPad + Android)
> **Legacy references:** S1, Capacitor contingency (Tech §2)

## Context

S1 validated the installed PWA end-to-end on both phones over HTTPS staging: email-code sign-in, step-up, offline shell launch, second-cold-open update pickup, microphone recording in both hold-to-talk and tap-to-start/stop modes (after a gesture-handling fix), SSE reply playback with dedupe/resume across backgrounding and lock screen, `▶ Play reply` fallback for rejected autoplay (iOS), and closed-app Web Push including delayed delivery on iOS.

## Decision

Nilumi ships as an installed PWA on both phones. The Capacitor fallback path (ADR-015's contingency) is **not triggered** and is not purchased; it remains documented as the contingency if a future WebKit regression breaks a load-bearing capability.

Findings baked into the baseline:
- PWA updates require a second cold open to surface (network-first SW) — accepted behavior; the real app documents "relaunch to update."
- iOS rejected-autoplay after resume is a first-class `▶ Play reply` path, already specced in Architecture §14.1/§14.4.
- Tap-to-talk and hold-to-talk coexist on one button via a 400 ms press-duration split.
- iOS/iPad audio requires byte-range request support (implemented on the deployed app; mirrored in the real app's audio route).

## Alternatives

Capacitor wrap (native mic permission + APNs push without a second codebase) — rejected for now because the PWA met every acceptance criterion; Apple Developer account cost deferred until a trigger appears.

## Consequences

No native toolchain, no TestFlight/ad-hoc distribution, no separate iOS testing layer. Push remains Web Push (VAPID), signed per-member subscriptions in the real app. If WebKit later removes home-screen push or recording parity, this ADR is revisited and the Capacitor path activates with an ADR superseding this one.
