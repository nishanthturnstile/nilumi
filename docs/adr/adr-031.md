# ADR-031 — Visibility defaults and derivative existence privacy

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P2–P8. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the visibility defaults and derivative existence privacy choice within that experience.

## Decision

Ordinary family facts/preferences and child-subject facts default household. “For me”, “my note” and “remind me” default private to the authenticated member. Explicit owner share cues create shared memories. Household records are editable/forgettable by adults; only the original asserter may explicitly restrict a household memory to private, set ownership and scrub others' derivatives after an already-seen warning; shared private memories stay owner-editable. Activities/drafts are member-owned by default.

## Consequences and validation scope

Visibility of the underlying record governs references, presentations, speech, Recent summaries, history, export and caches. An activity cannot widen access. Unshare/forget invalidate derivative references without exposing hidden item existence. Secret identifiers are refused or masked; calendar is owner-private.
