# ADR-025 — No classifier runtime in the MVP

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P4. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the no classifier runtime in the mvp choice within that experience.

## Decision

Do not add an intent, health or PII classifier to the served MVP path. Deterministic secret handling and validated NLU remain authoritative. Optional offline embedding-kNN/PII experiments are deferred research, not mandatory P0 work.

## Consequences and validation scope

Revisit if NLU prompt-related p95 exceeds 2 seconds, LLM spend exceeds US$5/month, simple-command intent accuracy falls below 90% or secret recall below 100%. Classifiers for Vault/child access require their own scope and evidence.
