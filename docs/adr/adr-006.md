# ADR-006 — Typed predicate registry and cardinality

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P4. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the typed predicate registry and cardinality choice within that experience.

## Decision

Predicates define value type, allowed subjects, default visibility and cardinality. Enforce cardinality in visibility/owner-aware slots; provisional new:* predicates require admin review.

## Consequences and validation scope

Explicit sharing must not silently overwrite a household cardinality-one value. Typed validation precedes execution; free-form model predicates are not automatically accepted.
