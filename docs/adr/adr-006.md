# ADR-006 — Predicate registry with typed values and cardinality

> **Status:** Accepted
> **Baseline:** Revision 2, reviewed 6 Oct 2026; individual decision date not recorded
> **Origin:** Extracted from Architecture §21; existing ID and accepted meaning retained
> **Legacy references:** Original ADR only

## Context

Structured lookup and safe correction need a controlled vocabulary and predictable cardinality.

Sharing must not silently replace a household cardinality-one value. Explicit slot boundaries require typed predicates and visibility-aware indexes.

## Decision

predicates define value type, subject types, default visibility and cardinality.

## Alternatives

free-form predicates; pure-vector memory as text.

## Consequences

reliable structured lookup and conflict handling enforced by indexes; provisional `new:*` predicates need admin review.

Sharing conflicts are governed by [ADR-024](adr-024.md); default visibility is governed by [ADR-031](adr-031.md).
