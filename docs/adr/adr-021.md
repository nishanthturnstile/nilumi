# ADR-021 — Library use and scoped metered-vendor exception

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P0–P8. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the library use and scoped metered-vendor exception choice within that experience.

## Decision

Use Next.js, Turbopack, AI SDK, json-render and other eligible open-source libraries without adopting Vercel hosting, Workflow, Cron or other metered platform services. Purchased Vercel AI Gateway credits are the sole existing metered Vercel exception, with no paid plan or auto top-up.

## Consequences and validation scope

Pipecat/Python dependencies and any production media transport add operational/processor obligations. P1 records licences, pins and hosting limits before family use. Gateway budget controls and privacy policy are in ADR-022/036/017.
