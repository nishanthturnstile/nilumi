# ADR-010 — Undo-first confirmation instead of confidence thresholds

> **Status:** Accepted
> **Baseline:** Revision 2, reviewed 6 Oct 2026; individual decision date not recorded
> **Origin:** Extracted from Architecture §21; existing ID and accepted meaning retained
> **Legacy references:** Original ADR only

## Context

Frequent confirmation prompts would make everyday capture slower than a notes app; vague model confidence is not a reliable permission signal.

The modality review emphasizes a visible screen alongside speech. Transcript and result cards make writes inspectable and correction practical.

## Decision

accept deterministic, visible writes with Undo rather than asking on model confidence.

## Alternatives

thresholds on LLM self-reported confidence.

## Consequences

fewer questions, visible and reversible writes; clarification only on deterministic ambiguity.

Explicit health/allergy confirmation ([ADR-037](adr-037.md)) and irreversible forget confirmation remain exceptions.
