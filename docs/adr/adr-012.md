# ADR-012 — Application hosting and voice runtime gate

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P1. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the application hosting and voice runtime gate choice within that experience.

## Decision

Select Railway Singapore for the planned Next.js application, TypeScript worker and PostgreSQL. Add a separately deployed Python voice service only after verifying media transport, TLS/signaling, resource limits, concurrency, session lifecycle and deployment support. An HTTP deployment or SSE success does not establish WebRTC UDP reachability.

## Consequences and validation scope

SmallWebRTC is a local prototype choice. P1 compares proven self-hosted media support with an eligible managed WebRTC transport; processor/cost approval is required before adopting another vendor. A Dokploy VM remains an infrastructure exit option with an operations burden, not a mandatory migration. [Transport documentation](https://docs.pipecat.ai/client/concepts/choosing-a-transport).
