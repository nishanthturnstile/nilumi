# ADR-026 — Deferred Family Records Vault

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** deferred; Deferred. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the deferred family records vault choice within that experience.

## Decision

Defer document/photo extraction and Vault originals. P4 provides source provenance, content references and sensitive-input boundaries; future extraction can add immutable originals, masked chunks and region/page citations without a competing memory authority.

## Consequences and validation scope

No extractor or original-view step-up policy is selected. Prerequisites are pilot usefulness, approved processor/retention, masking tests, ownership/deletion/export design and budget. No numbered horizon order or mandatory initial Vault tables.
