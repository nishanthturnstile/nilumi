# ADR-009 — Pipecat and Sarvam prototype integration

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** selected for prototype; P0–P1. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the pipecat and sarvam prototype integration choice within that experience.

## Decision

Select Python Pipecat with Sarvam streaming: Saaras v4 realtime as the initial STT candidate, Bulbul v3 Ritu as the initial TTS candidate. Tap once opens a continuing foreground conversation. Evaluate English, Tamil and Tanglish from P0. Limit any keyterm context to authorized visible aliases. Use local SmallWebRTC for prototype testing; production transport/hosting is an explicit P1 gate.

## Consequences and validation scope

Pipecat v1.11.0 release notes explicitly add Saaras v4 support; older Sarvam integration guidance describes a v3-only restriction. Pin compatible released versions when implementing and test actual behavior. Existing REST/PCM phone acceptance does not validate this processor. Sources: [Pipecat release](https://github.com/pipecat-ai/pipecat/releases/tag/v1.11.0), [Sarvam realtime](https://docs.sarvam.ai/api/api-guides-tutorials/speech-to-text/realtime-streaming).
