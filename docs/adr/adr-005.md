# ADR-005 — Custom household memory layer

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P4. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the custom household memory layer choice within that experience.

## Decision

Implement typed memories, bi-temporal history, provenance, correction, sharing, retrieval and forgetting directly on PostgreSQL. Keep activity drafts and generated presentations separate from factual memory.

## Consequences and validation scope

A general memory framework does not replace Nilumi ownership, existence privacy and complete derived-content deletion. This carries implementation/audit cost and requires explicit retrieval and privacy gates.
