# ADR-005 — Custom memory layer instead of a memory framework

> **Status:** Accepted
> **Baseline:** Revision 2, reviewed 6 Oct 2026; individual decision date not recorded
> **Origin:** Extracted from Architecture §21; existing ID and accepted meaning retained
> **Legacy references:** Original ADR only

## Context

Memory needs typed predicates, bi-temporal history, exact provenance, owner-aware sharing and complete forget semantics.

The sharing review shows why generic visibility flips lose ownership and un-share rights. These requirements reinforce the framework comparison rather than introducing a second memory subsystem.

## Decision

implement memories, history, supersession, retrieval and forget directly.

## Alternatives

Mem0, Graphiti/Zep, Letta, Cognee, LangMem (why each falls short: [Tech Stack §4.2](../core/03-tech-stack.md#42-rejected-alternatives)).

## Consequences

we implement well-bounded logic ourselves; we get RLS privacy, predicate registry, span provenance, owner-only sharing and forget semantics that no framework provides on Postgres today.

The custom layer carries implementation and audit costs; privacy and retrieval gates still apply.
