# ADR-044 — Trusted model composition with json-render

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** selected for prototype; P0/P2. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the trusted model composition with json-render choice within that experience.

## Decision

Use AI SDK plus json-render to compose versioned Nilumi components: checklists, tables, timelines, text and simple diagrams with supporting controls. Nilumi owns React implementations, props, accessible behavior and action adapters. Validate schema, allowed nesting, bounds, references, visibility and current data revision before rendering.

## Consequences and validation scope

No arbitrary HTML/JS, dynamic imports, executable diagrams or model-authorized actions. Keep catalogue identifier nilumi-ui/1; isolate json-render patch/version format behind an adapter. Stable keys preserve interaction focus; reject stale output and fall back to last authorized view or deterministic text. A2UI/AG-UI/CopilotKit are research references, not mandatory competing protocols.
