# ADR-011 — graphile-worker and transactional scheduling

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P1/P5. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the graphile-worker and transactional scheduling choice within that experience.

## Decision

Use graphile-worker in an always-on TypeScript worker for reminders, maintenance, embeddings, forget-journal append and backups. Schedule occurrences transactionally with domain changes; jobs carry IDs and recheck authority before work. Delivery is at least once with idempotent claims.

## Consequences and validation scope

The existing S5 synthetic experiment is evidence only. P5 repeats ≥200 occurrence dispatches within 60 seconds with no stale sends; P8 repeats recovery. No Redis or workflow subscription is selected.
