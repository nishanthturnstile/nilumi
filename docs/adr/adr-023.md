# ADR-023 — Email-code identity and optional step-up

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P1. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the email-code identity and optional step-up choice within that experience.

## Decision

Use Better Auth email OTP and multi-session support for invite-only adults. Use 90-day sliding HttpOnly sessions and self-service device revocation. Optional platform WebAuthn or a fresh email code supplies step-up for export, forget-all and private views after 24-hour inactivity; privileged freshness is 10 minutes.

## Consequences and validation scope

No primary passkey, magic login link, public signup or admin takeover after first sign-in. Verify current supported/security-fixed Better Auth version at implementation. Mailbox takeover is account takeover. PWA sign-in/recovery must work without switching the user to a browser tab.
