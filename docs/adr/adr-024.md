# ADR-024 — Owner-only explicit memory sharing

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P4. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the owner-only explicit memory sharing choice within that experience.

## Decision

Private memories become shared only by explicit owner request. Shared rows retain an immutable owner, readable by both adults, with edit/forget/unshare restricted to that owner. Sharing is not a correction and cannot silently overwrite a household singleton.

## Consequences and validation scope

Safe entity projections avoid leaking private aliases. Unsharing scrubs the other adult’s derived activities/presentations and invalidates caches; it cannot retract information already seen or heard.
