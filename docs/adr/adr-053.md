# ADR-053 — Owner bootstrap and invitation emails

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P1. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the owner bootstrap and invitation emails choice within that experience.

## Decision

An owner-only database script creates the founding household/first adult admin and refuses an existing household. It is not HTTP-accessible. Admin subsequently adds adult/child profiles and relationships. It does not record privacy acknowledgement.

## Consequences and validation scope

Invitations from no-reply@nilumi.in contain inviter, plain https://app.nilumi.in link, install instructions and in-app email-code guidance, no login token. Resend is allowed until first sign-in; failures visible in Admin. Last-admin/self-role protection and no post-sign-in takeover remain required.
