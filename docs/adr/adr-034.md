# ADR-034 — Deferred household-helper access

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** deferred; Deferred. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the deferred household-helper access choice within that experience.

## Decision

Keep list access within authenticated household adults for MVP. Helpers are deferred, with list-only scoped grants, expiry, revocation and isolation prerequisites. External contacts remain entities rather than users.

## Consequences and validation scope

No helper role/grant migration is mandatory now. Production privacy and primary legal review gate any external user.
