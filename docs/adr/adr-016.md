# ADR-016 — Production, staging and marketing origins

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P1. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the production, staging and marketing origins choice within that experience.

## Decision

Use https://app.nilumi.in for production application, API and auth; https://staging-app.nilumi.in for isolated staging; https://nilumi.in for static marketing. Keep app/API/auth same-origin with host-only cookies. Attach the final production origin before installed-app acceptance; staging credentials, subscriptions and data remain separate.

## Consequences and validation scope

The existing spike uses https://staging.nilumi.in as its historical canonical origin. Do not change that harness during this documentation revision. Moving to a new origin requires fresh install/session/push validation; marketing cannot access application cookies. Consolidates ADR-055.
