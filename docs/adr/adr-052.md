# ADR-052 — Close S-VGW for a restricted founding-household pilot

> **Status:** Accepted and validated for the restricted founding-household pilot
> **Baseline:** October 10, 2026
> **Origin:** Owner: “proceed with all your recommendation and lets close it” following the explanation of remaining proofs and workarounds
> **Amends:** ADR-046/ADR-051 evidence requirements and quota-test ordering; retains the US$1.05 aggregate ceiling

Run the bounded live quota test independently of the unresolved negative test.
A fresh Team-attributed US$1 cumulative key must first pass the existing chat
and 768-dimension embedding controls. Carry all prior counted charges forward.
Do not replay halted runs, use runtime/evaluation keys, or repeat the failed
negative profiles. Preserve exact live quota rejection and used-key shutdown.

Accept published provider forwarding/retention contracts plus pinned SDK
serialization as founding-pilot storage evidence. This is documentary evidence,
not direct downstream observation or a zero-data-retention claim.

Accept a narrowly scoped founding-household exception for the missing explicit
`no_providers_available` live rejection. All four historical HTTP 500 tests stay
failed. Restrict runtime to the verified OpenAI chat/embedding roles, keep
`disallowPromptTraining:true`, supported `store:false`, managed credentials and
`only:[openai]`, and disable fallbacks. Before transport, a local guard must reject
unknown, ineligible or stale/unavailable catalog routes. Check routing/cost
receipts and stop on errors. The remaining uncertainty is Vercel's exact
pre-provider rejection behavior. Keep the prepared report local, as requested.

Implement durable household acknowledgement, withdrawal veto, accepted-evidence
version, spending reservations and role halts in PostgreSQL, with queued/worker
rechecks before transport. Test restart persistence, concurrent reservations and
withdrawal before dispatch. An acknowledgement must be explicitly recorded by
the authorized adult after the notice is explained; this decision is not that
acknowledgement and does not authorize inventing it.

Close S-VGW as **accepted — restricted founding-household pilot, with documented
negative-test exception** only after the compensating controls, live quota and
shutdown pass. The first real family call still requires deployed/configured
durable controls and current household acknowledgement. Production, external
households, helpers, kid mode and commercial use retain their existing gates.
