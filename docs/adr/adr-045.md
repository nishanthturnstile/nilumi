# ADR-045 — Optional read-only calendar through Home

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P7. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the optional read-only calendar through home choice within that experience.

## Decision

Each adult may connect their own Google primary calendar read-only. Connection never creates a Nilumi user; invite-only identity remains. Events are private to the connecting member, separate from memory, and appear in Home timelines/briefs. Calendar failure leaves core Home useful.

## Consequences and validation scope

Verify actual scopes, OAuth publication/refresh-token behavior, privacy page/origin and consent before enabling. Explain unverified-app warning where applicable. Disconnect revokes tokens, cancels sync and scrubs cached events plus affected activities/presentations/briefs/speech. No calendar writes, CalDAV or household-wide calendar access.
