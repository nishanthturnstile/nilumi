# ADR-013 — Pinned model roles and evaluation changes

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P0–P8. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the pinned model roles and evaluation changes choice within that experience.

## Decision

Use named nlu, answer, embed, stt and tts roles with exact model IDs, voice and processor versions pinned in configuration. Switch only through eligibility review, frozen evaluation and scoped shadow verification. Never deploy a latest alias silently.

## Consequences and validation scope

S3 selected a hosted parsing candidate within synthetic correctness scope, not production latency acceptance. Embedding changes require versioned configurations and backfill. Voice selection and multilingual session acceptance are separate.
