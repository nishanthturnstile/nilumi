# ADR-013 — Model roles pinned in config, changed only through the eval gate

> **Status:** Accepted
> **Baseline:** Revision 2, reviewed 6 Oct 2026; individual decision date not recorded
> **Origin:** Extracted from Architecture §21; existing ID and accepted meaning retained
> **Legacy references:** Original ADR only

## Context

Silent model changes can alter parsing, answers and embedding compatibility without a code diff.

Routing through role aliases preserves provider freedom without binding domain code to models. Offline evaluation followed by shadow comparison protects served family answers.

## Decision

code names roles (`nlu`, `answer`, `embed`, `stt`, `tts`) and config pins exact model IDs.

## Alternatives

hard-coded models; "latest" aliases.

## Consequences

protection from silent provider changes; switching providers is a config change plus an eval report.

Exact IDs and voice selection remain S2–S4 outputs. Embedding changes need a new config and backfill, not an incompatible in-place swap.
