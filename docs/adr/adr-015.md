# ADR-015 — Next.js PWA with a Capacitor escape hatch

> **Status:** Accepted
> **Baseline:** Revision 2, reviewed 6 Oct 2026; individual decision date not recorded
> **Origin:** Extracted from Architecture §21; existing ID and accepted meaning retained
> **Legacy references:** Original ADR only

## Context

One web app minimizes development and deployment overhead, but installed iPhone mic and push behavior can block adoption.

WebKit determines capabilities regardless of framework. The review records Home Screen push restrictions, session-reset reports and a Next.js background-launch watch item; convenience alone does not prove acceptability.

## Decision

ship a Next.js 16 App Router PWA with Serwist service worker first.

## Alternatives

native apps (React Native/Expo), PWA only with no escape hatch.

## Consequences

one codebase and one deployable; if iOS mic or push friction fails S1, wrap the same web app in Capacitor, which requires an Apple Developer account.

S1 is pending after S6. Capacitor requires Apple Developer membership and TestFlight or ad-hoc distribution; the choice is contingent on the phone spike.
