# ADR-043 — Deferred durable runs, leases and fencing

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** deferred; Deferred. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the deferred durable runs, leases and fencing choice within that experience.

## Decision

If bounded agent runs are later selected, store run state/steps/events in PostgreSQL and schedule by ID using graphile-worker. Use lease renewal and compare-and-swap revisions to fence stale writers. Waiting releases leases. Internal effects and receipts remain atomic; external dispatch without a receipt becomes outcome_unknown and never automatically redispatches.

## Consequences and validation scope

Pause/cancel stop future work, not completed effects. Prerequisites: approved run type, budget, broker capabilities, visibility, effect reconciliation and restart tests. Run tables/transitions are documentation extension points only; no P1 migration requirement. Briefs remain deterministic scheduled assembly, not general runs.
