# ADR-042 — Action broker and immutable proposal approval

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P3/P6. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the action broker and immutable proposal approval choice within that experience.

## Decision

A shared TypeScript action broker validates actor, visibility, input provenance, capability, target revision, policy and budget before deterministic executors. Generated controls carry server-issued action references, never model-generated permission. Requested reversible actions use Undo; proactive changes require immutable approvals.

## Consequences and validation scope

Proposal snapshot binds member, action, arguments/hash, source/target revision and expiry. Approve rechecks all gates and executes once; Edit creates a new proposal, Reject closes it. Voice approval must name/bind the specific proposal; stale/expired changes do nothing and explain why. Future external effects retain this broker but are deferred.
