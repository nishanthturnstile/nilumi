# ADR-003 — "LLM as parser, code as executor"; no agent framework

> **Status:** Accepted
> **Baseline:** Revision 2, reviewed 6 Oct 2026; individual decision date not recorded
> **Origin:** Extracted from Architecture §21; existing ID and accepted meaning retained
> **Legacy references:** D11

## Context

Household writes must be authorized, deterministic and independently testable even when language interpretation is probabilistic.

The workflow comparison finds no benefit in adding 5–8 durable events to turns that finish in seconds. Agent graphs add latency and nondeterminism to the fixed MVP pipeline. Visual routine building (n8n) is deferred unless it becomes a product requirement and another service is acceptable.

## Decision

the core turn pipeline is a fixed sequence of AI SDK calls plus deterministic executors.

## Alternatives

free-form tool-calling agent loop; LangChain/LangGraph; Mastra/OpenAI Agents.

## Consequences

at most two LLM calls per turn, deterministic and testable writes, templated confirmations; open conversation is deferred to [Architecture §20.6](../02-architecture.md#206-conversation-mode-horizon-h7) over the same executors.

Constrained conversation mode remains H7; it reuses the same executors and privacy controls.
