# ADR-003 — Continuing conversation with deterministic execution authority

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P0–P4. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the continuing conversation with deterministic execution authority choice within that experience.

## Decision

The model interprets input and composes trusted presentations; backend code authorizes and executes every household effect. Each foreground follow-up is an authoritative turn with active-activity context. Use the constrained parser/validator/executor pipeline for domain commands, with at most two LLM calls for extraction and optional grounded synthesis; presentation generation must fit that bounded turn budget or occur as a separately reserved presentation-only request. Speech processing does not create an independent agent action loop.

## Consequences and validation scope

General autonomous runs, delegation and external effects remain deferred. Their extension points are ADR-042/043; no initial run tables or mandatory agent-framework migration. Continuing conversation is not conditional on building those runs. Consolidates applicable authority policy from ADR-041.
