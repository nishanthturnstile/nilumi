# ADR-050 — Allocate US$1 to the isolated S-VGW canary

> **Status:** Accepted
> **Baseline:** October 10, 2026
> **Origin:** Owner instruction: “use 1 doller … pls prpceed”
> **Legacy references:** None
> **Supersedes / superseded by:** Amends only the S-VGW allowance in [ADR-046](adr-046.md); its privacy and release gates remain required

## Context

The signed-in dashboard rejects a US$0.10 budget. An authenticated quota edit
also returned HTTP 400: `limitAmount` must be at least 1. The owner authorized
US$1 from the existing purchased-credit balance for this verification.

## Decision

The isolated S-VGW key uses a US$1 cumulative gateway budget and a US$1 durable
reservation cap. Failed and uncertain calls retain their reservations. The
four-probe manifest remains bounded; the allowance is a ceiling, not a spending
target. Dedicated Team-attributed runtime and evaluation keys retain their
existing ceilings and refresh periods; the outer team budget remains US$10
monthly. These key ceilings are not additive spending entitlements.

Backend creation/readback gates independent synthetic probes. The quota probe
additionally requires its own supported edit and propagated readback. The US$1
minimum prevents lowering a tiny canary's budget to actual spend, so that live
proof remains pending. This allocation does not waive the proof, authorize
deliberate exhaustion beyond US$1, or enable family traffic.

The canary key is revoked on every exit. A failed probe's report and ledger are
preserved; no key or ledger reset turns it into a successful run.

## Alternatives

US$0.10 through the dashboard or quota API is unsupported. Spending purchased
credits solely to reach exhaustion is deferred while a supported bounded proof
method is unresolved. Injected SDK quota tests remain local evidence.

## Consequences

Account budgets, positive routing and used-key revocation can be verified now.
Negative policy and exact live quota acceptance remain separate required proofs.
The household acknowledgement remains a separate gate before family requests.
