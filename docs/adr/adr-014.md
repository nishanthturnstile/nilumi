# ADR-014 — Forget scrubs source and derived content

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P4. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the forget scrubs source and derived content choice within that experience.

## Decision

Forget irreversibly scrubs source text, memories/history, embeddings, activity content, presentation snapshots, evidence references, queued speech and eligible caches. Commit redaction, tombstone and journal outbox atomically. Worker appends to the encrypted recovery journal; restore replays it before serving.

## Consequences and validation scope

Undo is recoverable retraction; forget cannot be undone. Provider-retained copies and old encrypted backups have disclosed limits. Content-reference indexing makes deletion auditable; presentation-only derivatives are included.
