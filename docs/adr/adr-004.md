# ADR-004 — PostgreSQL is the only stateful service

> **Status:** Accepted
> **Baseline:** Revision 2, reviewed 6 Oct 2026; individual decision date not recorded
> **Origin:** Extracted from Architecture §21; existing ID and accepted meaning retained
> **Legacy references:** Original ADR only

## Context

Facts, access policy, jobs and receipts must agree transactionally without maintaining several state authorities.

Railway supports resident workers and LISTEN connections. Transactional occurrence enqueue avoids saving reminders without jobs; separate queues and sync services add operational responsibility.

## Decision

Postgres stores data, vectors, FTS, jobs, pub/sub invalidations, access policy, receipts, traces and budgets.

## Alternatives

Redis/cache/queue, object storage for state, vector DB, graph DB.

## Consequences

one database to back up, secure and reason about; reminder creation and job enqueue can be transactional; operating Postgres well is a first-class responsibility ([Architecture §17.2](../02-architecture.md#172-backups-and-restore-drill)).

R2 still holds encrypted backups and later immutable Vault originals; this record does not remove those storage uses.
