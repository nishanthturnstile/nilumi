# ADR-004 — PostgreSQL as the state authority

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P1. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the postgresql as the state authority choice within that experience.

## Decision

PostgreSQL stores household records, vectors, FTS, activity state, presentations, jobs, receipts, policy, traces and budgets. LISTEN/NOTIFY carries invalidations rather than authoritative content. Use R2 for encrypted recovery objects, not a competing state database.

## Consequences and validation scope

Business effects and receipts can commit together. No Redis, separate vector database or hosted workflow service is needed initially. PostgreSQL operations and recovery are first-class obligations.
