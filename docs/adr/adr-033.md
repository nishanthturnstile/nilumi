# ADR-033 — Offline Home projections and desired-state sync

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P2/P3. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the offline home projections and desired-state sync choice within that experience.

## Decision

Use member-filtered Postgres invalidation → SSE → authorized refetch. Persist only approved list/task/Inbox projections, never private memory, calendar text or arbitrary generated screens. Partition caches/queues by household/member/device; wipe on logout/account switch and next online revocation contact. Home offline reconstructs trusted views from those permitted projections. Exclude raw saved requests, health evidence, memory spans, calendar text and generated summaries from offline Inbox/task fields; opaque IDs and generic status are sufficient. Resolve fresh scoped action references after reconnect without changing original idempotency or desired state.

## Consequences and validation scope

Checking and unchecking send explicit desired boolean, expected revision and idempotency key; retries cannot invert state. Conflicts return current revision and a visible resolution choice, never silently use completion-only monotonic merging. Preserve queued operations through restart; unshare/forget evicts affected data before refresh. Offline devices cannot be remotely wiped until contact.
