# ADR-018 — Atomic action receipts and coordinated responses

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** planned for MVP; P1–P4. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the atomic action receipts and coordinated responses choice within that experience.

## Decision

Every action carries actor, activity/turn, target revision, explicit desired state, request hash and idempotency key. Commit effect, operation, content references and receipt in one transaction. Replay an authorized identical request using its receipt; reject key reuse with different content. Resume only commands without a committed receipt.

## Consequences and validation scope

The shared response stream feeds text, presentation and speech from committed outcomes. Partial success is visible. A crash after commit or interrupted audio cannot duplicate or undo that effect. Python forwards input and consumes this response stream.
