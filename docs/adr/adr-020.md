# ADR-020 — Next.js React application and trusted renderer

> **Decision status:** Accepted current baseline, 2026-10-10.
> **Delivery status:** selected for prototype; P0–P2. Acceptance of a decision does not establish implemented or production-validated behavior.

## Context

The voice-first PWA uses one dynamic Home canvas and persistent activities. This record owns the next.js react application and trusted renderer choice within that experience.

## Decision

Select Next.js App Router/React with same-origin Hono APIs, TanStack Query for server state, and a PWA service worker. Use AI SDK for application-side typed streams and json-render for model composition over an owned trusted component registry. Domain actions remain server authorized.

## Consequences and validation scope

Keep free open-source libraries and existing UI tokens. Production packages are planned, not installed merely because a spike contains Next.js. Use AI SDK UI data streams; experimental RSC generative UI is not a production dependency. Renderer catalogue versions, limits and fallback views require tests.
