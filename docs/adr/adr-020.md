# ADR-020 — Next.js (latest, Turbopack) PWA with Hono mounted in route handlers and TanStack Query

> **Status:** Accepted
> **Baseline:** Revision 2, reviewed 6 Oct 2026; individual decision date not recorded
> **Origin:** Extracted from Architecture §21; existing ID and accepted meaning retained
> **Legacy references:** D5, D6, D7

## Context

The PWA, API and auth need one deployment with typed contracts and a practical offline list experience.

Next.js brings manifest/PWA hooks and a standalone deployment; static export drops route handlers, cookies and headers. Vite is still a sound shell but loses this one-process shape; SvelteKit offers no decisive benefit. TanStack persistence avoids a separate local-first sync server.

## Decision

use Next.js 16 App Router with Turbopack, Hono mounted at `app/api/[[...route]]/route.ts`, Better Auth routes in the same app, Serwist PWA support and TanStack Query for API state.

## Alternatives

Vite SPA + Hono server (baseline), SvelteKit, static export.

## Consequences

one same-origin app/API deployment, React ecosystem fit, typed Hono client, offline-friendly query cache and no separate server package.

This refines [ADR-001](adr-001.md) and [ADR-015](adr-015.md), rather than superseding their channel or fallback choices. Cache boundaries and SSE are recorded in [ADR-033](adr-033.md).
